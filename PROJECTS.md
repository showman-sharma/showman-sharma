# Project Portfolio

A curated map of my public GitHub work. This page separates current showcase projects from research artifacts, educational implementations, and older experiments so that the repository history is easier to interpret.

## Showcase

### [drug_ae_reasoner](https://github.com/showman-sharma/drug_ae_reasoner)
**Biomedical reasoning · Knowledge graphs · SapBERT · FAISS · RxNorm · CADEC · OAE**

A multi-source reasoning system for tracing interpretable paths between drug mentions and adverse-event concepts. This is one of the strongest research-oriented artifacts on this account and accompanies my work accepted at IEEE ICDH 2026.

### [codegen-ui-research](https://github.com/showman-sharma/codegen-ui-research)
**LLM code generation · HumanEval · Prompting · Inference-time refinement · Evaluation**

Experimental work comparing seed generation and post-generation enhancement strategies for code LLMs, including structured reasoning, self-consistency, self-planning, self-refinement, recursive criticism, progressive hints, and test-based enhancement.

### [agentic_rag](https://github.com/showman-sharma/agentic_rag)
**RAG · LangGraph · FAISS · Sentence Transformers · Local/cloud LLMs**

A modular retrieval and generation package with document loading, chunking, embedding, vector search, provider abstraction, classic RAG, and an agentic workflow.

### [Bio-inspired-clustering](https://github.com/showman-sharma/Bio-inspired-clustering)
**Bio-inspired ML · Similarity search · Clustering · Unsupervised learning**

An older but distinctive line of experimentation deriving similarity-search and mean-shifted clustering ideas from biologically inspired hidden-unit learning, with an application to fake-news classification.

### [whitepapers](https://github.com/showman-sharma/whitepapers)
**Enterprise AI · Agents · Banking · Responsible AI · Technical writing**

A growing collection of reference-backed technical whitepapers on applied AI systems and enterprise use cases.

### [Gradient Ascent Syndicate](https://github.com/gradient-ascent-syndicate)
**Open-source education · AI/ML curriculum · Community engineering**

An open initiative I help run to build a comprehensive, implementation-first AI/ML curriculum spanning foundations, classical ML, deep learning, modern LLM systems, and agents.

## AI systems and application engineering

### [ai_blog_workflow](https://github.com/showman-sharma/ai_blog_workflow)
An automated AI/ML publishing workflow that retrieves news and research, synthesizes material with LLMs, generates channel-specific content, and publishes through GitHub Actions and WordPress integrations.

### [EZ-DOC.AI](https://github.com/showman-sharma/EZ-DOC.AI)
Historical GenAI prototype exploring prompt-driven document generation with Cohere, Flask, and DOCX output.

### [customer-support-automation](https://github.com/showman-sharma/customer-support-automation)
Historical prototype combining Gmail workflow automation with ML-based support-email classification and feedback-driven routing.
